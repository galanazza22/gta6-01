**Solmar Heat** — an open-world crime game in the spirit of GTA 6, built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

Deke Reyes owes club owner Marcus Vale $2,000. Fixer Lena Cruz has five jobs that will clear the debt — if the cops, the rivals, and Solmar City itself don't get him first. Explore a sun-soaked coastal city on foot and by car, steal anything with wheels, outrun a five-star wanted level, fight rival gangs, and finish all five story missions.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and click **NEW GAME**. No build step, no network — the game is static files under `game/` (Three.js vendored as `game/vendor/three.min.js`, all sound synthesized with WebAudio).

**Controls:** WASD walk / drive · mouse look / aim · E enter / exit car · click shoot · R reload · Shift sprint · Space jump / handbrake · P pause · M mute. Progress, money and mission state save to localStorage.
